# Reference results

These files are the author's own benchmark runs on Apple Silicon (`mps`), kept as a record of
what each release measured at the time. They are **not** regenerated by the test suite.

| File | Produced by | Release |
|---|---|---|
| `rcwe_validation_report_v03.json` | `rcwe bench validate` | v0.3 |
| `rcwe_extreme_and_symbolic_v04.json` | `rcwe bench extreme` | v0.4 |
| `rcwe_telemetry_and_code_v05.json`, `rcwe_live_dashboard_v05.html` | `rcwe bench dashboard` | v0.5 |
| `rcwe_universal_prediction_report.json` | `rcwe-predict` | v0.6 |
| `rcwe_realworld_benchmarks_v06.json` | `rcwe bench realworld` | v0.9 (re-run with the residual Transformer baseline) |
| `rcwe_phase2_v07_report.json` | `rcwe bench phase2` | v0.7 |
| `rcwe_deep_corpus_report_v08.json` | `rcwe bench corpus` | v0.8 |
| `rcwe_v09_multimodal_rl_swarm_report.json` | `rcwe bench v09` | v0.9 |

Numbers depend on hardware, PyTorch version and the code revision. To see what the current
code does on your machine, run the suites yourself; fresh reports are written to
`./rcwe_output/` (or `$RCWE_OUTPUT_DIR`):

```bash
rcwe bench --list
rcwe bench realworld
```

A run of every suite with the current release on Linux/CPU is summarised in
[`../BENCHMARKS.md`](../BENCHMARKS.md).
